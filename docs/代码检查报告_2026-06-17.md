## 🔴 编译错误

### 1. `RPCActivity` 类型未定义 — FinderExtension target 编译失败

**严重性**: Critical — 阻塞编译
**文件**: `Shared/RPC/RPCSession.swift:203, 215, 235, 238, 252, 293, 332, 345, 355`

**问题**: `RPCActivity` 定义在 `Shared/Models/DebugLogEntry.swift:70-94`，但该文件 **未被添加到 Xcode 项目**（`project.pbxproj` 中无任何 `DebugLogEntry` 引用）。`RPCSession.swift` 是两个 target 共享的源文件，FinderExtension target 编译时找不到 `RPCActivity` 类型。

**错误信息**:
```
error: cannot find type 'RPCActivity' in scope
  private let onActivity: @Sendable (RPCActivity) -> Void
```

**修复**: 将 `Shared/Models/DebugLogEntry.swift` 添加到 **两个 target**（mac-right-menu 和 FinderExtension）的 "Compile Sources" build phase。

---

### 2. `DebugLogView.swift` 引用 `AppState.debugLog` / `AppState.clearDebugLog()` — 属性不存在

**严重性**: Critical — 阻塞编译（即使文件加入项目）
**文件**: `mac-right-menu/Views/DebugLogView.swift:18, 43, 47, 53`

**问题**: `DebugLogView` 访问 `appState.debugLog`、`appState.clearDebugLog()`，但 `AppState` 中没有这两个成员。`AppState` 只有 `executionLog` 和 `clearLog()`。

**修复**: 在 `AppState` 中添加：
```swift
@Published private(set) var debugLog: [DebugLogEntry] = []
func clearDebugLog() { debugLog.removeAll() }
```
并在 `RPCServer` 的 `onActivity` 回调中将 `RPCActivity` 转换为 `DebugLogEntry` 追加到 `debugLog`。

## 🟡 潜在问题

### 4. `Process.launchPath` 使用已废弃 API

**严重性**: Medium
**文件**: `mac-right-menu/ViewModels/AppState.swift:194, 522`

**问题**: 使用 `task.launchPath = ...` 而非 `task.executableURL = ...`。`launchPath` 在 macOS 10.13+ 已被标记为废弃。

```swift
// 当前（废弃）:
task.launchPath = "/usr/bin/pluginkit"

// 推荐:
task.executableURL = URL(fileURLWithPath: "/usr/bin/pluginkit")
```

**影响**: 当前不影响功能，但未来 SDK 可能移除支持。

---

### 5. `saveConfiguration()` 双重调用问题（FIXME.md #1 — 仍然存在）

**严重性**: Medium
**文件**: `mac-right-menu/ViewModels/AppState.swift:8-11, 296-301, 304-309, 312-317, 320-325, 331-336, 341-349`

**问题**: `configuration` 的 `didSet` 调用 `saveConfiguration()`，所有便捷访问器（`isEnabled`、`appItems`、`actionItems` 等）又显式调用一次。每次变更触发两次序列化 + 两次 RPC 广播。

**建议**: 删除便捷访问器中的 `saveConfiguration()` 调用，依赖 `didSet` 自动保存。

---

### 6. `executeCommand` 的 `nonisolated` 标记（FIXME.md #2 — 仍然存在）

**严重性**: Medium
**文件**: `mac-right-menu/ViewModels/AppState.swift:394`

**问题**: `AppState` 是 `@MainActor` 类，`executeCommand` 标记为 `nonisolated` 意味着任意线程可调用。方法内部访问 `NSPasteboard.general`（需主线程）和 `Process().waitUntilExit()`（阻塞线程）。

---

### 7. Shell 命令路径注入风险（FIXME.md #3 — 仍然存在）

**严重性**: Medium
**文件**: `mac-right-menu/ViewModels/AppState.swift:523`

**问题**: 文件路径未转义直接拼接到 shell 命令：
```swift
let substituted = cmd.replacingOccurrences(of: "{}", with: command.files.joined(separator: " "))
```
含空格、`$`、反引号、`;` 的路径可导致命令注入。
